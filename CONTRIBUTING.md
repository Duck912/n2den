# Contributing

## Reporting issues

Report bugs and request features with GitHub issues on the n2den repository.
Search the existing issues first. For a bug, give the n2den commit hash, the
steps to reproduce it, your system details and the log file.

## Pull requests

- The build must pass.
- Keep each pull request to one topic.
- Follow the [coding guidelines](docs/policies/Coding.md) and the style of the
  surrounding code.
- AI-assisted contributions follow the [AI policy](docs/policies/AI.md).
- See the [build documentation](docs/Build.md) to build and test your changes.
- Keep the SPDX licence headers in existing files, and add one to new files.
